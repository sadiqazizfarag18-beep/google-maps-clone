## 🚀 البدء السريع

### افتح index.html في VS Code
1. اضغط زر الفأرة الأيمن على `index.html`
2. اختر "Open with Live Server"
3. الموقع سيفتح تلقائياً! 🌐

## 📱 الاستخدام

- **البحث**: اكتب اسم المكان
- **الموقع**: اضغط الزر الأزرق
- **المفضلة**: احفظ الأماكس المهمة
- **المسار**: احصل على معلومات الاتجاهات
